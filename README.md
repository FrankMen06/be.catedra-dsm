# API DSM - Backend

Backend desarrollado con **Node.js**, **Express** y **Firebase Admin SDK** para la gestión de usuarios, eventos, asistencia, comentarios y autenticación.

## Tecnologías utilizadas
- Node.js
- Express
- Firebase Admin SDK
- Firestore
- JSON Web Token
- bcryptjs

## Instalación
Clonar el repositorio actual

ingresar a la carpeta "be" del proyecto y hacer

``` npm i```

luego para levantarlo hacer

``` npm run dev```
